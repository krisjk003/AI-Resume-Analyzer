# 🤖 AI Resume Analyzer

An AI-powered full-stack web application that analyzes resumes, evaluates ATS compatibility, extracts key information from PDF documents, and provides intelligent feedback to help users improve their resumes for technical and professional roles.

The platform combines modern web technologies with Large Language Models (LLMs) to deliver actionable insights, identify missing skills, and generate ATS-friendly recommendations in real time.

---

## ✨ Features

- 📄 PDF Resume Upload
- 🤖 AI-powered Resume Analysis
- 📊 ATS Compatibility Evaluation
- 🎯 Skill Gap Detection
- 💼 Job-readiness Assessment
- 📝 Resume Improvement Suggestions
- ⚡ Real-time Analysis
- 🌐 Responsive Web Interface
- 🔒 Secure Backend Processing

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/krisjk003/AI-Resume-Analyzer.git

cd AI-Resume-Analyzer
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
OPENAI_API_KEY=your_api_key
```

Start the backend

```bash
npm run server
```

Start the frontend

```bash
npm run dev
```
